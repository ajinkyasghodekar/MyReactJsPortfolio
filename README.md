# My React JS Portfolio - Under Development 

Welcome to my personal portfolio! This project is built using ReactJS and showcases my skills, projects, and contact information. It is designed to be fully responsive and provides a simple and interactive interface.

## Live Demo

You can check out the live demo of the portfolio here:

[my-react-js-portfolio-nu.vercel.app](https://my-react-js-portfolio-nu.vercel.app)

## Features

- **Responsive Design**: The portfolio is fully responsive, ensuring a seamless experience across all devices.
- **Contact Form**: A contact form to reach out to me directly, with real-time validation.
- **Contact Details**: Quick access to my phone number, WhatsApp, and email.
- **Modern UI**: Clean, simple, and user-friendly interface built with ReactJS and Bootstrap.
- **Projects Showcase**: Display of my skills, projects, and relevant work experience.

## Technologies Used

- **ReactJS**: The front-end library used to build the user interface.
- **Bootstrap**: For responsive and modern UI components.
- **Axios**: For handling HTTP requests (used in the contact form).
- **React Icons**: For adding icons in the contact section.
- **Vercel**: Deployed on Vercel for easy and fast hosting.
